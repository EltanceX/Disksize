# 阶段 7：矩形树图

日期：2026-11-15；多层级扩展：2026-11-17

## 使用与容量口径

从最近会话进入“空间浏览”，切换“树图”。“显示到级别”可选 0～6，默认级别 3；当前目录为级别 0，级别 0 只显示目录整体。下钻后以新目录重新计级，所选深度在当前浏览页面内保留。目录标题栏和内部嵌套矩形展示父子关系，颜色随级别由深蓝变浅蓝，图例对应各级别。

单击内部色块选中最深的可见节点，单击目录标题栏选中该目录。双击同一个目录色块或标题栏直接进入对应目录，也可选中后点击“进入目录”下钻。文件、灰色汇总区与当前目录自身不会触发双击下钻；连续点击不同色块只选中后者。系统返回、工具栏返回和面包屑均逐级返回。文件和目录都能查看原有详情，宽屏沿用右侧详情，手机使用抽屉。既有索引可以直接使用，无须重新扫描。

同一目录内容区域内，面积按所选口径下的已知容量分配，目录标题栏不参与子项比例计算。逻辑大小和报告占用沿用索引聚合与硬链接归属结果，切换口径后按该容量重新查询与布局。符号链接不跟随，共享硬链接可以是零贡献；目录自身 blocks 仍计入报告占用。颜色表示深度，不编码容量或文件类型。

每个目录未单独返回的子项、像素面积过小的项目和目录自身占用合并为灰色“其余小项 / 目录自身”。这些已知字节保留面积，不会因为分页或绘制限制而消失。灰色区域可切回其所属目录的列表查看子项，不作为实际目录下钻。零贡献条目不强行分配面积，列表和详情继续可查。

Partial 等已聚合结果可绘制已知容量，并提示未知范围；不完整条目的角落显示三角标记。尚在扫描、聚合或中断后未形成可加总结果时，不绘制暂定比例。零已知容量与仍有未知范围分别提示。会话不存在、跨请求 revision 变化或服务连接失败时清除旧画面并提示重试；已不可用的会话不持续自动轮询。

## 有界查询与绘制

- JSON `treemap` 查询沿用现有 Pigeon/Binder `queryIndex`。深度扩展不改变当前 schema 4 或 native v3 协议；历史索引无需迁移或重扫。
- 请求接受 `depth: 0..6`，省略时默认 3。每个目录最多返回 100 个容量最大的直接子项，使用现有 `children_logical` / `children_allocated` 排序索引；请求不接受名称排序、分页游标或超过 100 的 limit。
- 当前目录仍通过顶层 `entries` 返回子项；`treemap.groups` 包含展开目录及其子项，按目录容量降序优先展开。全局最多返回 300 个后代节点、48 个目录分支，节点与分支序列化文本预算为 300,000 字符。到达预算时设置 `truncated`，未展开子树仍显示为整体。
- 同时返回当前目录总量、未单独返回的容量、直接子项数、零贡献数和含未知范围的子项数。查询前后核验 revision，UI 也要求树图、目录详情、根汇总和祖先链的 revision 一致。
- 各目录未单独绘制的容量按“目录总量 − 已绘制子项容量”计算，包含目录自身占用。计数汇总在 SQLite 内扫描相应目录，成本随直接子项数增加；不把完整子项列表或整棵树传到 Dart。
- 面积小于 900 个逻辑像素的项目随父目录内容区域尺寸合并；过窄或过矮的目录保持整体。全图最多布局 350 个矩形，含当前目录、后代与各目录余量。squarified 算法逐层分配内容区域，浮点边界闭合，几何测试验证面积、不重叠与命中。
- 一层 `CustomPainter` 在 `RepaintBoundary` 中绘制，无逐节点 Widget 树；最多绘制 48 个标签。标签按矩形尺寸和系统字号裁剪/省略，名称沿用控制符与原始字节显示规则。
- 命中检测使用相同的矩形集合，按绘制逆序优先命中深层节点。语义节点提供级别、名称、容量、选中状态和点击操作；展开目录的语义点击区域使用标题栏，最大数量为 350。绘制期间不查询数据库，不读取目标文件内容。

## 2026-11-15 单层版本实测

沿用 Xiaomi sheng、Android 16/API 36、arm64、4 KiB 页、Impeller/Vulkan。正常入口双 ABI debug APK 已通过 su 覆盖安装，历史会话保留；实际打开已有 `/data/data` 的 188,441 节点会话并检查树图截图。

- `flutter analyze` 无问题，30 项 Flutter 测试通过，其中新增 10 项树图几何、状态和交互测试。
- Android `IndexStoreTest` 为 `OK (8 tests)`，含新增的 1,003 直接子项回归；4 项 JVM 协议测试通过。
- profile 端到端测试通过：真实扫描和索引、210 个直接子项返回 100 项、两种口径、目录下钻返回，以及 Stress 子目录 101 个矩形的命中和选中。样本使用普通扫描，root 索引复用相同查询与画图入口。
- Android Lint：0 错误、8 项现有警告；两个 ABI 均构建成功。真机 PNG 已检查，360×800 双倍字号与 1280×900 分栏由 Widget 测试覆盖。

最终 profile 采集 45 帧，截图转换发生在采样结束之后：

| 指标 | 测量值 |
| --- | ---: |
| build P95 | 10.566 ms |
| raster P95 | 17.079 ms |
| totalSpan P95 | 21.741 ms |
| 100 节点 squarified 布局均值（1,000 次） | 12.612 µs |

帧指标包含连续选中与右侧详情更新，是这台设备、当前分辨率与样本的运行记录；raster P95 略高于 16.7 ms，不能宣称所有帧稳定达到 60 FPS。totalSpan 还包含流水线等待，不能把 build 与 raster 简单相加当作刷新率。大目录计数汇总仍需 SQLite 遍历其直接子项，本阶段没有重新执行百万直接子项或其他设备的性能矩阵。
