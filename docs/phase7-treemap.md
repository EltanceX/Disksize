# 阶段 7：矩形树图

日期：2026-11-15

## 使用与容量口径

从最近会话进入“空间浏览”，切换“树图”。树图只展示当前目录的直接子项；点击色块选中，再点击“进入目录”下钻，系统返回、工具栏返回和面包屑均逐级返回。文件和目录都能查看原有详情，宽屏沿用右侧详情，手机使用抽屉。既有索引可以直接使用，无须重新扫描。

面积以当前目录在所选口径下的已知总量为分母。逻辑大小和报告占用沿用索引聚合与硬链接归属结果，切换口径后按该容量重新查询与布局。符号链接不跟随，共享硬链接可以是零贡献；目录自身 blocks 仍计入报告占用。颜色仅区分项目，同一节点在同一会话中保持同色，不编码容量或文件类型。

未单独返回的子项、像素面积过小的项目和目录自身占用合并为灰色“其余小项 / 目录自身”。这些已知字节保留面积，不会因为分页或绘制限制而消失。灰色区域只能切回目录列表查看子项，不作为实际目录下钻。零贡献条目不强行分配面积，列表和详情继续可查。

Partial 等已聚合结果可绘制已知容量，并提示未知范围；不完整条目的角落显示三角标记。尚在扫描、聚合或中断后未形成可加总结果时，不绘制暂定比例。零已知容量与仍有未知范围分别提示。会话不存在、跨请求 revision 变化或服务连接失败时清除旧画面并提示重试；已不可用的会话不持续自动轮询。

## 有界查询与绘制

- 新增 JSON `treemap` 查询，沿用现有 Pigeon/Binder `queryIndex`，不改变 schema 3 或 native 协议。
- 每次最多返回 100 个容量最大的直接子项，使用现有 `children_logical` / `children_allocated` 排序索引；请求不接受名称排序、分页游标或超过 100 的 limit。
- 同时返回当前目录总量、未单独返回的容量、直接子项数、零贡献数和含未知范围的子项数。查询前后核验 revision，UI 也要求树图、目录详情、根汇总和祖先链的 revision 一致。
- 顶部 100 项之外的容量按“目录总量 − 已返回项容量”计算，包含目录自身占用。计数汇总在 SQLite 内扫描当前目录，成本随直接子项数增加；不把完整子项列表或整棵树传到 Dart。
- 面积小于 900 个逻辑像素的项目随画布尺寸合并；最多布局 101 个矩形。squarified 算法在较短边上选择长宽比更好的条带，浮点边界闭合，几何测试验证面积、不重叠与命中。
- 一层 `CustomPainter` 在 `RepaintBoundary` 中绘制，无逐节点 Widget 树；最多绘制 48 个标签。标签按矩形尺寸和系统字号裁剪/省略，名称沿用控制符与原始字节显示规则。
- 命中检测使用相同的矩形集合。语义节点提供名称、容量、选中状态和点击操作；最大数量同样为 101。绘制期间不查询数据库，不读取目标文件内容。

## 实测结果与限制

沿用 Xiaomi sheng、Android 16/API 36、arm64、4 KiB 页、Impeller/Vulkan。正常入口双 ABI debug APK 已通过 su 覆盖安装，历史会话保留；实际打开已有 `/data/data` 的 188,441 节点会话并检查树图截图。

- `flutter analyze` 无问题，30 项 Flutter 测试通过，其中新增 10 项树图几何、状态和交互测试。
- Android `IndexStoreTest` 为 `OK (8 tests)`，含新增的 1,003 直接子项回归；4 项 JVM 协议测试通过。
- profile 端到端测试通过：真实扫描和索引、210 个直接子项返回 100 项、两种口径、目录下钻返回，以及 Stress 子目录 101 个矩形的命中和选中。样本使用普通扫描，root 索引复用相同查询与画图入口。
- Android Lint：0 错误、8 项现有警告；两个 ABI 均构建成功。真机 PNG 已检查，360×800 双倍字号与 1280×900 分栏由 Widget 测试覆盖。

最终 profile 采集 45 帧，截图转换发生在采样结束之后：

| 指标 | 测量值 |
| --- | ---: |
| build P95 | 10.566 ms |
| raster P95 | 17.079 ms |
| totalSpan P95 | 21.741 ms |
| 100 节点 squarified 布局均值（1,000 次） | 12.612 µs |
| 根目录树图查询（含 Binder 与 JSON） | 26.185 ms |
| Stress 绘制矩形 / 根查询返回项 | 101 / 100 |

帧指标包含连续选中与右侧详情更新，是这台设备、当前分辨率与样本的运行记录；raster P95 略高于 16.7 ms，不能宣称所有帧稳定达到 60 FPS。totalSpan 还包含流水线等待，不能把 build 与 raster 简单相加当作刷新率。大目录计数汇总仍需 SQLite 遍历其直接子项，本阶段没有重新执行百万直接子项或其他设备的性能矩阵。
