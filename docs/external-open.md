# 使用其他应用打开

目录列表和大文件列表的详情中提供“使用其他应用打开”；树图选中文件或目录后，也可直接点击同名按钮。文件按扩展名选择查看器，目录交给兼容的文件管理器，由 Android 显示应用选择界面。返回 DiskSize 后保留选中项和滚动位置。

打开的是设备上当前路径的内容。快照只保存扫描记录，不保存文件副本；原文件可能已删除、移动或改变。无法读取、类型改变或没有兼容应用时显示说明，仍可在详情复制完整路径。

## 路径与授权

- 共享存储目录优先使用系统 ExternalStorageProvider 的位置 URI，支持主存储、当前用户的存储卷，以及 root 扫描的 `/data/media/<当前用户>` 别名。文件管理器能否访问由它自己的权限和系统限制决定。
- Root 扫描得到的当前用户 `/data/media/<当前用户>/...` 普通文件映射到对应的共享存储挂载路径，再按普通 UID 检查和提供只读授权。
- 普通应用身份可读的其他目录和文件通过 DiskSize 的 DocumentsProvider 提供，只授予读取权限。文件授权限于所选文件；目录授权限于所选子树，不能通过相对路径或指向范围外的链接扩大范围。打开的文件描述符另行校验类型、设备号、inode 和实际路径。
- 临时位置最多保留最近 16 个，有效期为 24 小时，不提供持久授权或写入授权。系统 Files 的“DiskSize · 已选位置”入口可显示这些仍有效的位置。其他应用原有的独立访问权限不受此限制。
- 自有 provider 每层目录最多返回前 1000 项，并提示从 DiskSize 中选择更深目录。系统共享存储 provider 不受本应用的这个上限影响。
- Root 扫描权限不能传给其他应用。其他应用私有目录等普通 UID 不可读路径会给出提示，可复制路径到支持 Root 的文件管理器。
- Android 应用数据隔离可能把其他应用的私有目录隐藏成 `ENOENT`。对 `/data/data`、`/data/user`、`/data/user_de` 及扩展卷中其他应用的路径返回 `ENOENT` 时，说明“无法访问或确认是否存在”，不据此断言已删除；DiskSize 自身可见目录中真实缺失的文件仍提示已不存在。
- 符号链接和特殊文件不显示打开按钮。非 UTF-8 路径及达到 Android 路径长度上限的路径无法直接交接，可在详情查看或复制原始路径信息。

打开操作不修改扫描索引、快照或原文件，不新增 root 内容读取接口。数据库 schema 与扫描协议保持不变；Pigeon 新增按会话 ID 和节点 ID 打开的异步接口，原生端从索引读取路径，不接受界面传入任意路径。

- 系统 Files 实际打开应用私有测试目录，并在当前界面找到其唯一测试文件，验证进入所选位置。

- Android Lint：0 错误、8 项现有警告，无新增警告。
